# Statystyki

Gdy pomiar odwiedzin jest włączony, na górnym pasku Studio jest zakładka **Statystyki**.

Widać tam zbiorcze liczby: ile osób czyta które strony. Nie ma listy osób ani adresów. Przycisk **Otwórz statystyki** otwiera ten sam widok w nowej karcie.

Część ruchu znika za blokerami reklam, więc liczby są niższe niż rzeczywista liczba wejść.
